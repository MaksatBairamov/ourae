# 👥 Team Roles and Responsibilities

This document outlines the key roles and responsibilities for the Ourae project team. Clear role definition helps us stay coordinated, make decisions faster, and maintain product quality.

---

## 🎯 Maksat Bairamov — Product Owner / Lead Frontend

**Primary Responsibilities:**
- **Roadmap** – Define product vision and feature priorities
- **Priorities** – Decide what gets done and when
- **UI Consistency** – Ensure design language is calm, minimal, and coherent
- **Feature Approval** – Review and approve feature specifications
- **Merge Approval** – Final code review and merge authority for main branch
- **Architecture Direction** – Guide technical decisions and system design

**Decision Authority:** Final approval for UI/UX, architecture, roadmap, and merge conflicts.

---

## 🛠️ Nizami — Feature Developer

**Primary Responsibilities:**
- **Feature Implementation** – Build core features and new functionality
- **Smaller Screens** – Optimize layouts for diverse mobile screen sizes
- **Helper Logic** – Develop utility functions and helper modules
- **Fixes** – Address bugs and issues as they arise

**Collaboration:** Works with Mykhailo on backend integration and with Vitalii on UI refinement.

---

## 🎨 Vitalii — Frontend / UI Support

**Primary Responsibilities:**
- **Reusable Components** – Create and maintain shared UI components
- **Styling** – Implement consistent, accessible CSS and visual design
- **Responsiveness** – Ensure components work across device sizes
- **Animations** – Add smooth, intentional transitions and micro-interactions
- **UX Polish** – Refine user experience and emotional tone

**Collaboration:** Partners with Maksat on design direction and with Nizami on component adoption.

---

## 🔧 Mykhailo — Backend / Logic / Testing

**Primary Responsibilities:**
- **API Routes** – Build and maintain Vercel API endpoints
- **Security Improvements** – Implement secure patterns and secret management
- **Testing** – Write unit tests and integration tests for backend logic
- **Async Handling** – Manage async operations, error boundaries, and cleanup
- **AI Logic Improvements** – Enhance AI request handling and response validation

**Collaboration:** Works with Maksat on architecture decisions and with Nizami on feature integration.

---

## 📋 How We Work Together

### Decision Making
- **Product & Roadmap:** Maksat decides, team inputs
- **Architecture:** Maksat leads, team discusses trade-offs
- **Feature Specs:** Team collaborates, Maksat approves
- **Code Quality:** Respective owners with Maksat final approval
- **UX/Design:** Maksat leads, Vitalii executes, team reviews

### Daily Communication
- Share updates on issue progress
- Ask for help early when blocked
- Review each other's work before marking done
- Keep code clean and well-documented

### Definition of Done
Before marking any task complete:
- ✅ Feature works correctly
- ✅ No TypeScript errors
- ✅ No console errors
- ✅ Responsive UI (tested on multiple screen sizes)
- ✅ Clean code structure
- ✅ Tested locally before PR
- ✅ Short PR description included

- **Feature Implementation Help** → Ask Nizami or relevant specialist
